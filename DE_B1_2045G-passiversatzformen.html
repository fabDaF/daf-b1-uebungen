Alternativen zum Passiv

Lesen Sie die Beispielsätze. Welche Alternativen gibt es zum Passiv? Beachten Sie die hervorgehobenen Strukturen.

1. Man kann das Problem lösen. (Passiv: Das Problem kann gelöst werden.)

2. Das lässt sich machen. (Passiv: Das kann gemacht werden.)

3. Das ist machbar. (Passiv: Das kann gemacht werden.)

4. Das ist zu schaffen. (Passiv: Das kann geschafft werden.)

Schritt 1: Was ist „man + Aktiv"?

Schritt 2: Was bedeutet „sich lassen"?

Schritt 3: Wofür stehen die Adjektive -bar und -lich?

Schritt 4: Was drückt „sein + zu + Infinitiv" aus?

Passiversatzformen — Die 4 Alternativen

  • 1. man + Aktiv: Man kann das Problem lösen. (= Das Problem kann gelöst werden.)
  • 2. sich lassen + Infinitiv: Das lässt sich machen. (= Das kann gemacht werden.)
  • 3. -bar/-lich Adjektive: Das ist machbar. (= Das kann gemacht werden.)
  • 4. sein + zu + Infinitiv: Das ist zu schaffen. (= Das kann/muss geschafft werden.)

📋 Regel

1. man + Aktiv

Struktur: man + Aktiv

Bedeutung: Aussage über die Möglichkeit, etwas zu tun

„Man kann das Problem lösen."
„Man muss die Aufgabe erfüllen."

2. sich lassen + Inf.

Struktur: Subjekt + lässt/ließen sich + Infinitiv

Bedeutung: etwas ist möglich / kann getan werden

„Das lässt sich machen."
„Das Problem lässt sich lösen."

3. -bar/-lich Adj.

Struktur: Subjekt + sein + Adjektiv (-bar / -lich)

Bedeutung: etwas hat die Eigenschaft, getan zu werden

„Das ist machbar." (= „Das kann gemacht werden.")
„Das ist löslich." (= „Das kann gelöst werden.")

4. sein + zu + Inf.

Struktur: Subjekt + sein + zu + Infinitiv

Bedeutung: Möglichkeit oder Notwendigkeit

„Das ist zu schaffen." (= „Das kann geschafft werden.")
„Das ist zu beachten." (= „Das muss beachtet werden.")
