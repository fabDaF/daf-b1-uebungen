🎯 Akkusativ-Ergänzungen
Das direkte Objekt im Satz — die Antwort auf „Wen?“ oder „Was?“
Was ist eine Akkusativ-Ergänzung?
Viele Verben brauchen ein direktes Objekt. Man fragt danach mit „Wen?“ (Personen) oder „Was?“ (Sachen).

Beispiel: „Ich lese ein Buch.“ — Was lese ich? → ein Buch (Akkusativ).
Beispiel: „Er besucht seinen Bruder.“ — Wen besucht er? → seinen Bruder (Akkusativ).

Wichtigste Regel: Nur beim Maskulinum ändert sich der Artikel: der → den, ein → einen. Bei Femininum, Neutrum und Plural bleibt der Artikel gleich.

📋 Akkusativ-Formen im Überblick

GenusNominativAkkusativ
Maskulinumder / ein Mannden / einen Mann
Femininumdie / eine Fraudie / eine Frau
Neutrumdas / ein Kinddas / ein Kind
Pluraldie Kinderdie Kinder

Auch Possessivartikel und kein folgen diesem Muster: mein → meinen Bruder, kein → keinen Kaffee.
