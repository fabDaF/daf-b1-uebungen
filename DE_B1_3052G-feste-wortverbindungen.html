🔍 Grammatik entdecken
Lies die Sätze mit den hervorgehobenen Verbindungen:

Er hat eine Entscheidung getroffen.
Sie hat einen Bericht verfasst.
Er hat eine Frage gestellt.
Sie hat einen Antrag gestellt.
Er hat Rücksicht genommen auf sie.
Was sind „feste Wortverbindungen“?
Welches Verb gehört zu „Entscheidung“?
Welches Verb gehört zu „eine Frage“?
„Er nimmt Rücksicht auf sie.“ — Was bedeutet das?

📋 Häufige feste Wortverbindungen (Nomen + Verb)

NomenVerbBeispiel
eine EntscheidungtreffenEr trifft eine Entscheidung.
eine Frage / einen AntragstellenSie stellt eine Frage.
Rücksichtnehmen aufEr nimmt Rücksicht auf sie.
einen Berichtverfassen / erstattenSie verfasst einen Bericht.
VerantwortungübernehmenEr übernimmt Verantwortung.
